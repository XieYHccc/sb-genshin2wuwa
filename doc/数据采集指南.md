# 数据采集指南（对应 plan §3）

先按 plan §10.1 搭好 `.venv`，各电脑上的实际环境见 `本地环境与进度.md`。用到的脚本是 `capture.py` 和 `ae_check.py`；DC-AE 权重会在第一次运行 `ae_check.py` 时自动下载。

下面所有命令都在仓库根目录下运行。先激活环境：

```bash
source .venv/Scripts/activate
```

（PowerShell 用 `.venv\Scripts\Activate.ps1`）

---

## 第 0 步：游戏设置（两边必须完全一致）

| 项 | 怎么设 |
|---|---|
| 显示模式 | **窗口化 1920×1080**（不要用独占全屏，否则可能截到黑屏） |
| 画质 | 两边都用最高档；**关闭动态模糊**；关 HDR |
| 帧率 | 两边都锁 60 |
| UI | 尽量隐藏（见下面的说明） |
| 游戏内时间 | 08:00–16:00（**会跑出这个范围，见第 3 步的"控制游戏内时间"**） |
| 天气 | 只要晴天 |
| 镜头 | 默认 FOV，第三人称，镜头稍微拉远一点，让角色小一些 |

**关于分辨率**：如果显示器是 4K（3840×2160），用"无边框全屏"，截下来就是 4K。截图本身没问题，但每张 PNG 有 10MB 以上，而且两款游戏的渲染分辨率很容易不一致。**建议两边都用窗口化 1920×1080。** 脚本只截客户区（不含标题栏），也已经处理了 DPI 缩放。

**关于 UI**：两款游戏都没有一个通用的"走路时隐藏全部 UI"开关，具体能做到什么程度和版本有关，请你在游戏里确认一下。脚本的 UI 过滤器会检测四个角的边缘密度：小地图、右上角图标会落在角上，看到这些就把这一帧丢掉。如果实际情况是 UI 隐藏不掉，导致大部分帧都被 `UI` 过滤器丢弃，把 probe 结果告诉我，我改成"裁掉固定 UI 区域"的方案。

## 第 1 步：验证截屏（每个游戏做一次，大约 2 分钟）

开着游戏，运行：

```bash
python capture.py --list-windows
```

确认列表里有游戏窗口。原神一般是 `原神 / YuanShen.exe`，鸣潮一般是 `鸣潮 / Client-Win64-Shipping.exe`。

```bash
python capture.py --game genshin --probe
```

运行后 3 秒内切到游戏，脚本会抓一帧，存到 `data/probe/`，并打印检查结果：

- `✗ 抓到的是黑屏` → 改成窗口化，再试一次
- `客户区不是 1920x1080` → 调整游戏分辨率
- 打开 `data/probe/` 里的图片，确认画面正确、没有被别的窗口挡住

然后对鸣潮也做一次：

```bash
python capture.py --game wuwa --probe
```

如果 `--list-windows` 里看到的标题和预设不一样，可以加 `--window "标题正则"` 手动指定。

## 第 2 步：试采 + DC-AE 闸门（go/no-go，大约 15 分钟）

先每边采 60 张试一下：

```bash
python capture.py --game genshin --session 00 --target 60
```

```bash
python capture.py --game wuwa --session 00 --target 60
```

再跑重建检查：

```bash
python ae_check.py --images data/10_frames/genshin/s00
```

```bash
python ae_check.py --images data/10_frames/wuwa/s00
```

结果在 `data/ae_check/s00/`，每张对照图是 **左原图 | 中重建 | 右误差×4**，文件名以 PSNR 开头，最低的排在最前面。重点检查这几样：**描边、远景植被、水面高光、草地纹理**有没有糊掉。

- 看起来没问题 → 继续
- 风格关键细节明显丢失 → 先停下，把对照图给我看。这种情况下需要换分辨率或者换 AE，后面采多少数据都没用

同时看一下 `data/10_frames/*/s00/session_stats_*.json` 里各过滤器的淘汰比例，用来判断阈值合不合适（见第 4 步）。

> 注意：s00 只是试采，正式训练时会排除掉，或者只用作验证集。

## 第 3 步：正式采集

### 采集方式

```bash
python capture.py --game genshin --session 01 --minutes 20
```

- 启动后切到游戏，**匀速步行或滑翔**，不要冲刺，不要快速转镜头
- **切出游戏窗口时自动暂停**；在游戏内打开菜单、地图、过场、剧情对话、战斗、传送时，按 **F9** 暂停，再按一次继续
- **F10** 或在控制台按 Ctrl+C 结束；`--target N` 或 `--minutes N` 达到后也会自动结束
- 控制台会实时显示有效帧数，以及各过滤器丢掉了多少帧
- 每一帧单独存盘，游戏崩溃也不会丢失已经存下的帧。用相同的 session 号重新运行会接着追加，并用已有的帧初始化去重

### 控制游戏内时间（重要）

游戏里的时间走得很快：**原神游戏内一天只有 24 分钟**（现实 1 分钟 = 游戏 1 小时），20 分钟的会话从早上采起，中途一定会入夜。已有的 s01 就是这样，原神约 12 分钟、鸣潮约 13 分钟的画面是黄昏或夜晚，离线过滤时整段扔掉了，有效帧只剩一半左右。

- 开采前把游戏时间调到 08:00
- 原神每采 8 分钟左右按 **F9** 暂停，用游戏内的时间调整把时间调回早上，再按 F9 继续
- 鸣潮同样开采前确认是白天，采集中留意天色，开始变暗就暂停、调时间
- 如果还是录进了黄昏或夜晚，不用删帧：在该会话目录下写一个 `exclude.txt`，一行一段要排除的时间（帧文件名里的时间戳，格式 `HH:MM:SS-HH:MM:SS 原因`），离线过滤会整段跳过。没有这个文件时，过滤脚本会自动判断，并在 `data/20_filtered/sheets/timeline_<游戏>_sNN.jpg` 里画出时间线供复核

### 隐藏不掉的固定叠加层

两款游戏隐藏 UI 后都还留着小块叠加层（原神右下角的 UID，鸣潮右下角的识别码和左上角的小图标）。**不用管**：离线过滤会自动检测出它们的位置，打包和推理时统一抹掉。

### 采集计划（每边，地貌按类型配平）

| 会话 | 地貌 | 时长 | 目标有效帧 |
|---|---|---|---|
| s01 | 草原丘陵 | 20 min | ~1000 |
| s02 | 山地岩壁 | 20 min | ~1000 |
| s03 | 水景湖岸 | 20 min | ~1000 |
| s04 | 林地 | 20 min | ~1000 |
| s05 | 混合，作为**验证集** | 15 min | ~500 |

两边的 session 号要和地貌一一对应（比如原神 s03 和鸣潮 s03 都是水景）。每边目标是 3000–5000 张有效帧。

**按地貌类型对应，不要按地名对应**。挑选路线的建议：

- 选**白天开阔、植被和地形多样**的区域，避开城镇、室内、洞穴、秘境
- 不要在一个小区域里来回绕圈，去重能挡住站着不动，但挡不住"同一片草地的 50 个角度"
- 镜头偶尔慢慢水平转一下，让天空和地面的比例有变化
- 鸣潮的地图色调普遍偏冷偏灰，原神偏绿，**这正是要学的风格差异**，不要为了"对齐"去刻意挑颜色相近的地方

### 去重/过滤阈值的含义（`capture.py` 顶部）

| 常量 | 默认 | 被丢的原因 |
|---|---|---|
| `LUMA_MIN/MAX` | 60 / 230 | 太暗（夜晚/洞穴）或过曝（白屏转场） |
| `SHARP_MIN` | 60 | 运动模糊、过场虚化 |
| `CORNER_EDGE_MAX` | 0.20 | 四角有 UI |
| `PHASH_MIN_DIST` | 6 | 和最近 300 张近似重复（站着不动） |
| `TARGET_FPS` | 1.5 | 采样频率 |

## 第 4 步：根据统计调阈值

每次会话结束后都会写一份 `session_stats_*.json`，`frames.csv` 里还有每一帧的亮度、清晰度、角落边缘密度和去重距离。正常情况下：

- `dup` 占 30–60% 是正常的
- **`blur` 或 `ui` 超过 30%**，说明阈值对这款游戏偏严：先用 F9 暂停，看看被丢的是不是确实是好帧，再改 `capture.py` 顶部的常量
- **修改阈值后，两款游戏要用同一套值**。离线阶段（plan §3.4）会再按两边各自的分布复核一次

---

## 不要做的事（安全边界）

- 不要为了"挂机自动走路"去用任何按键模拟、宏或者连点器。两款游戏都有内核级反作弊，脚本只做被动截屏，和 OBS 一样
- 不要公开分发采集到的截图数据集（版权，plan §3.8）

## 采完之后

把新采的会话拷到训练用的电脑的 `data/10_frames/` 下，然后依次运行：

```bash
python filter_frames.py
```

```bash
python pack.py
```

`filter_frames.py` 会重新扫描全部会话（逐帧特征有缓存，旧会话不会重复解码），输出 `data/20_filtered/report.txt`（各会话保留多少帧、各类丢了多少）和 `sheets/` 下的拼图，先看一眼时间线拼图和随机抽检拼图再打包。打包完就可以开新的训练 run，EDM 系数会在新 run 启动时自动重新标定。训练步骤见 `训练指南.md`。

目录结构：

```
data/
  probe/                      # 第 1 步的探测截图
  ae_check/<session>/         # 第 2 步的重建对照
  10_frames/
    genshin/s00..s05/*.png  + frames.csv + session_stats_*.json
    wuwa/s00..s05/...
```
